# Multiples Maze

Multiples Maze is a browser math game where the player starts at `1` and must move only through numbers in the 9-times table up to `108`. Choosing a wrong number resets the board and rerolls the hidden route.

## Play

Open `index.html` in a browser, or serve the folder with any static web server.

For installable/offline PWA behavior, host the app on HTTPS or run it from localhost:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8765/index.html`.
